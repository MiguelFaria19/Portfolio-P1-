# Portfólio P1 — Miguel da Silva Faria

Portfólio pessoal desenvolvido para a P1 de Laboratório de Programação Front End.

## Tecnologias

- Vite
- React
- TypeScript
- HTML semântico
- CSS responsivo

## Estrutura

```text
src/
├── Inicio.tsx
├── sobre.tsx
├── ph.tsx
├── contato.tsx
├── menu.tsx
├── main.tsx
└── index.css
public/
├── profile.svg
└── audio/
    └── portfolio-message.wav
```

## Executar

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Lint

```bash
npm run lint
```

## Partes do portfólio

O site possui Início, Sobre, Projetos/Habilidades, Contato e menu de navegação responsivo. Também inclui imagem, áudio, animação CSS e navegação otimizada para celular.
